# دليل تغذية نظام الذكاء الاصطناعي (AI Knowledge Base Guide)

يعتمد النظام على تقنية **RAG (Retrieval-Augmented Generation)**، مما يعني أنه يبحث في قاعدة البيانات عن معلومات ذات صلة قبل الإجابة على سؤل المستخدم.

لتغذية النظام بالمعلومات، لديك طريقتان:

---

## الطريقة 1: المحتوى التلقائي (Dynamic Content)
النظام مصمم لقراءة الجداول التالية تلقائياً من قاعدة البيانات:
1. **المقالات (Blog Posts)**: أي مقال تضيفه في جدول `posts` سيتم تحويله إلى معرفة.
2. **الكورسات (Courses)**: أي كورس تضيفه في جدول `courses` سيتم قراءته.

### الخطوات:
1. أضف المقال أو الكورس عبر لوحة التحكم (Admin Panel) أو مباشرة في قاعدة البيانات.
2. قم بتحديث "الذاكرة" (Vector Index) بتشغيل هذا الأمر:

```bash
npm run generate-embeddings
```

---

## الطريقة 2: معلومات يدوية (Manual/Hardcoded)
إذا كنت تريد إضافة معلومات عامة لا تنتمي لمقال أو كورس (مثلاً: "من هو محمد القضاة؟"، "ما هي خبراتي؟")، يمكنك إضافتها يدوياً في السكربت.

### الخطوات:
1. افتح الملف: `scripts/generate_embeddings.ts`
2. ابحث عن القسم `// Database likely empty. Seeding manual context...` (أو أضف مصفوفة يدوية).
3. يمكنك إضافة نصوصك هنا:

```typescript
const records = [
    // ... البيانات القادمة من الداتابيس
    // أضف معلوماتك اليدوية هنا
    {
        id: 'about-me',
        type: 'manual',
        content: 'محمد القضاة هو مهندس برمجيات خبير في Next.js...'
    }
];
```
4. احفظ الملف، ثم شغل الأمر:
```bash
npm run generate-embeddings
```

---

## ملاحظة هامة
بما أن قاعدة البيانات الخاصة بك (NeonDB) موجودة على السحابة (Cloud)، فإن تشغيل الأمر `npm run generate-embeddings` على جهازك **سيقوم بتحديث قاعدة البيانات الحية فوراً**. لا تحتاج لرفع الكود للسيرفر لتحديث المعلومات، فقط تشغيل السكربت محلياً كافٍ.
